# New machine setup

Everything needed to continue on another computer. Code, docs and deploy files are in
this repository. Secrets are **not**; recreate or copy them privately. Values are never
written here, only names.

## 1. Tools

Git, Docker Desktop (with Compose), Python 3.12 + [uv](https://docs.astral.sh/uv/),
Node.js 20.9+.

```bash
git clone https://github.com/shahil5z/document-intelligence-analysis.git
cd document-intelligence-analysis
uv sync
python3 scripts/generate_env.py      # creates .env with fresh random secrets
cd frontend && cp .env.example .env.local && npm ci
```

## 2. Secrets to recreate (local `.env`, see `.env.example`)

| Name | Notes |
| --- | --- |
| `JWT_SECRET_KEY` | random, at least 32 characters (generated by `generate_env.py`) |
| `POSTGRES_PASSWORD` | random (generated) |
| `REDIS_PASSWORD` | random (generated) |
| `OPENAI_API_KEY` | your OpenAI key; only needed for `/ask` |
| `CLIENT_IP_HEADER_SECRET` | optional; same value as `DIP_CLIENT_IP_SECRET` in the frontend |
| `STORAGE_S3_ACCESS_KEY_ID`, `STORAGE_S3_SECRET_ACCESS_KEY` | only if `STORAGE_BACKEND=s3`/`oci` |

Frontend (`frontend/.env.local`, see `frontend/.env.example`): `NEXT_PUBLIC_API_URL`
(not secret), optional `DIP_CLIENT_IP_SECRET`.

Local secrets can simply be regenerated; nothing in the local database needs to be kept.

## 3. Production server

- The production env file is `/opt/dip/app/.env.production` **on the server only**
  (template: `.env.production.example`). It is not in Git and does not need to be on
  your laptop.
- The 1 GB VM uses `docker-compose.micro.yml` together with `docker-compose.prod.yml`
  and `deploy/caddy/Caddyfile.micro`.
- SSH access needs the private key. The key is kept in the `Downloads\ORACLE CLOUD`
  folder on the old PC; copy it to the new machine privately (USB drive or password
  manager), never through Git. Then:

```bash
ssh -i <path-to-private-key> ubuntu@<server-ip>
```

## 4. Files that intentionally stay off GitHub

`.env`, `.env.bak`, `.env.production`, `frontend/.env.local`, any `env` file holding
keys, and the SSH private key. Copy only what you still need, privately.
